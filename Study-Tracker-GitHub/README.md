# Study Tracker

Личный трекер учёбы на вашем компьютере. Записывайте занятия, время,
решённые задания и заметки. В приложении есть таймер, отчёты, недельные планы,
календарь активности, достижения и профиль с фотографией.

Каждая установленная копия хранит собственные данные. После установки
зависимостей приложение работает без интернета.

## Что понадобится

Установите Python 3.10 или новее с https://www.python.org/downloads/.
В Windows при установке отметьте **Add Python to PATH**.
Для первого запуска потребуется интернет и любой современный браузер.

## Скачивание

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив в постоянную папку, например «Документы».
3. Откройте папку с файлами `bot.py` и `requirements.txt`.
4. Откройте в ней терминал.

В Windows введите `powershell` в адресной строке Проводника и нажмите Enter.
В Linux используйте пункт «Открыть в терминале» в меню папки.
В macOS откройте Terminal, введите `cd `, перетащите папку проекта в окно
и нажмите Enter.

## Первый запуск в Windows

Выполните команды по очереди. После каждой нажимайте Enter и ждите завершения.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

## Первый запуск в Linux или macOS

В терминале из папки проекта выполните

```bash
bash start.sh
```

Скрипт создаст окружение Python, установит зависимости и запустит приложение.
Если команда python3 отсутствует, сначала установите Python.

## Открытие сайта

Когда появится строка `Running on http://127.0.0.1:5000`, откройте
**http://127.0.0.1:5000** в браузере.

Терминал должен оставаться открытым во время работы.
Для остановки нажмите **Ctrl+C**. Этот адрес работает на компьютере,
где запущено приложение.

## Повторный запуск

Откройте терминал в той же папке.

Windows

```powershell
.\.venv\Scripts\python.exe bot.py
```

Linux и macOS

```bash
bash start.sh
```

## Первые шаги

1. На странице **Сегодня** нажмите **Добавить цель**, например «Python».
2. Выберите цель в таймере и нажмите **Начать занятие**.
3. Завершите таймер, укажите задания и сохраните результат.
4. Для прошлого занятия используйте **Записать вручную**.
5. В **Статистике** доступны отчёты, темп занятий и планы на неделю.
6. В **Дневнике** сохраняйте изученные темы и сложности.
7. Иконка справа сверху открывает профиль с календарём и достижениями.

Фото можно загрузить через **Изменить профиль → Сохранить профиль**.
Поддерживаются PNG, JPEG и WebP до 5 МБ. Фото обрезается по центру до квадрата.

Таймер продолжает считать время при закрытой вкладке и во время сна компьютера.
Перед сохранением можно исправить минуты и дату. Текстовые заметки
требуют нажатия кнопки сохранения.

## Данные и резервные копии

После запуска в папке проекта автоматически появятся

- `study_bot.db` — занятия, планы, дневник, фото и состояние таймера.
- `study_bot.secret` — локальный ключ защиты форм.
- `.venv` — окружение Python с установленными библиотеками.
- `backups` — резервные копии базы перед обновлением её структуры.

Чтобы сохранить резервную копию, остановите приложение и скопируйте
`study_bot.db` в отдельное место.

Для переноса на другой компьютер установите приложение и перенесите
свой `study_bot.db` в папку проекта до запуска.
Если там уже есть база, сначала сохраните её копию.

## Обновление

Остановите приложение и сделайте резервную копию базы.
Замените файлы кода новой версией, сохранив свою базу.
Затем обновите зависимости и снова запустите сайт.

Windows

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Linux и macOS

```bash
.venv/bin/python -m pip install -r requirements.txt
```

## Частые проблемы

**Python не найден.** Установите Python и откройте терминал заново.
В Windows проверьте опцию Add Python to PATH.

**Не найден bot.py или requirements.txt.** Перейдите в распакованную папку
проекта. Все команды нужно выполнять из неё.

**В Ubuntu или Debian не создаётся окружение.** Установите модуль venv

```bash
sudo apt install python3-venv
```

Затем повторите запуск.

**Ошибка No module named.** Повторите установку зависимостей и запускайте
программу через Python из папки .venv.

**Порт 5000 занят.** Возможно, сайт уже запущен в другом терминале.
Откройте адрес сайта или остановите предыдущий процесс.
Можно выбрать другой порт.

Linux и macOS

```bash
STUDY_TRACKER_PORT=5001 bash start.sh
```

Windows

```powershell
$env:STUDY_TRACKER_PORT = "5001"
.\.venv\Scripts\python.exe bot.py
```

Тогда адрес будет http://127.0.0.1:5001.

**После переноса нет записей.** Проверьте, что ваш файл study_bot.db
лежит рядом с запускаемым bot.py. Разные копии проекта используют разные базы.

## Публикация своей версии

Для GitHub нужны код, README, requirements.txt, start.sh, .gitignore
и папки routes, static, templates, tests.

Перед созданием ZIP или ручной загрузкой через сайт GitHub исключите базы,
ключи, backups, .venv и __pycache__. В базе находятся личные записи и фотография.

Правила .gitignore применяются при работе через Git. Они не исключают файлы
из архива, созданного вручную. Если файл уже был добавлен в Git раньше,
новые правила сами его из истории не удаляют.

## Для разработчиков

Стек — Flask, SQLite, JavaScript и Pillow для обработки аватаров.

- bot.py — запуск сервера.
- application.py — настройки приложения и общие проверки форм.
- routes/study.py — цели, занятия и история.
- routes/reports.py — статистика и недельные планы.
- routes/profile.py — профиль, фотография и календарь.
- routes/journal.py — дневник.
- routes/timer.py — API таймера.
- database.py — данные и миграции.
- analytics.py — статистика.
- templates/ — HTML.
- static/ — CSS и JavaScript.
- tests/ — автоматические проверки.

Запуск тестов

```bash
.venv/bin/python -m unittest discover -s tests -v
```

В Windows используйте `.\.venv\Scripts\python.exe`.
Тесты используют временные базы.
