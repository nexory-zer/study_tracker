# 📚 Study Tracker

**Учись регулярно и следи за своим прогрессом.**

Личный трекер занятий, который работает на твоём компьютере и открывается в браузере. Записывай время учёбы, решённые задания и заметки, ставь планы на неделю и смотри, как меняется твоя активность.

**Python · Flask · SQLite · HTML / CSS / JavaScript**

## Возможности

| Раздел | Что можно делать |
| --- | --- |
| 🎯 Цели | Создавать направления учёбы и сохранять занятия по каждой цели |
| ⏱️ Таймер | Начинать занятие, завершать его и сохранять результат; добавлять занятия вручную |
| 📊 Статистика | Смотреть время занятий, выполненные задания и темп обучения |
| 🗓️ Планы | Задавать недельные цели по минутам, заданиям и активным дням |
| 📝 Дневник | Записывать изученные темы, сложности и заметки |
| 👤 Профиль | Загружать фотографию, смотреть календарь активности и достижения |

После установки зависимостей приложение работает без интернета. Данные хранятся локально в SQLite; у каждой установленной копии своя база.

## Быстрый запуск

Нужны Python **3.10+**, Git и браузер. Для установки зависимостей нужен интернет.

### 1. Скачать проект

```bash
git clone https://github.com/nexory-zer/study_tracker.git
cd study_tracker/Study-Tracker-GitHub
```

Можно также выбрать **Code → Download ZIP**, распаковать архив и открыть терминал в папке с `bot.py` и `requirements.txt`.

### 2. Запустить

**Linux / macOS**

```bash
bash start.sh
```

Скрипт создаст виртуальное окружение, при необходимости установит библиотеки и запустит сервер.

**Windows — PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

### 3. Открыть в браузере

Перейди на **[http://127.0.0.1:5000](http://127.0.0.1:5000)**.

Терминал должен оставаться открытым. Для остановки нажми **Ctrl+C**. Сервер слушает только локальный адрес; приложение рассчитано на личное использование.

> В Ubuntu / Debian для создания окружения может понадобиться пакет `python3-venv`. Решения других проблем — в [подробной инструкции](Study-Tracker-GitHub/README.md#частые-проблемы).

## Первое занятие

1. На странице **Сегодня** добавь цель — например, «Изучить Python».
2. Выбери её в таймере и нажми **Начать занятие**.
3. После занятия останови таймер, укажи выполненные задания и сохрани результат.
4. В **Дневнике** запиши, что понял и где возникли сложности.
5. Загляни в **Статистику** и составь план на следующую неделю.

Таймер учитывает время при закрытой вкладке и во время сна компьютера. Перед сохранением можно исправить длительность и дату.

## Данные и резервные копии

После первого запуска рядом с `bot.py` появятся `study_bot.db` и `study_bot.secret`. В базе находятся личные записи и фотография; файл `.secret` содержит ключ защиты форм.

Чтобы сделать резервную копию, **останови приложение и скопируй `study_bot.db`** в отдельное место. Перед обновлением или переносом тоже сохрани копию базы.

Не загружай в публичный репозиторий базу, файл `.secret`, резервные копии и виртуальное окружение.

## Проверки для разработчиков

Из папки `Study-Tracker-GitHub`, после установки зависимостей:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

В Windows используй `.\.venv\Scripts\python.exe`. Тесты работают с временными базами.
